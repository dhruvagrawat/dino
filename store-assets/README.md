# Google Play store assets

Upload these in **Play Console → Store presence → Main store listing**.
Regenerate anytime with `node store-assets/gen.mjs`.

| File | Where it goes in Play Console | Spec |
|------|-------------------------------|------|
| `play-icon-512.png` | App icon | 512×512 PNG, 32-bit |
| `feature-graphic-1024x500.png` | Feature graphic | 1024×500 PNG/JPG |
| _screenshots_ (you add) | Phone screenshots | 2–8 images, min 320px, 16:9 or 9:16 |

## Screenshots
Capture from the emulator or a device while the app runs:
- Android Studio emulator → camera icon in the toolbar, **or**
- On device: Power + Volume-Down.

Good shots to grab: the **menu/home**, **gameplay** (mid-jump over a cactus),
the **shop**, the **modes** screen, and the **game-over** card.

The launcher icon and splash for the built app come from `mobile/assets/`
(generated by `mobile/scripts/gen-logo.mjs`) — these store assets are separate
and only used on the Play Store listing page.
